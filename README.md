## GerStudio Portfolio

Modern portfolio site for Mayank Meena, focused on:

- Product-first web development
- Blockchain and smart contract work
- Solo indie game development with Godot

## Stack

- Next.js (Pages Router)
- React
- next-themes

## Local Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

- `npm run dev`: start local development server
- `npm run build`: build production bundle
- `npm run start`: run production server
- `npm run lint`: run lint checks

## Project Structure

- `pages/index.js`: single-page portfolio content
- `components/Layout.js`: global shell and footer
- `components/Navbar.js`: sticky navigation
- `components/ThemeSwitch.js`: light and dark mode toggle
- `styles/globals.css`: visual system and responsive styles

## Deploy

Deploy on Vercel or any Node-compatible host:

```bash
npm run build
npm run start
```
